# Changelog

## 0.0.1

First internal build of AetherNet Browser. Not released.

Forked from [Clint Browser](https://github.com/jhaiian/ClintBrowser) (GPLv3) and reworked:

- **Built-in VPN** — a WireGuard tunnel carrying only this app's traffic, reachable from the menu
  and the home page, with a location picker.
- **Home page** — animated logo, search box, VPN card and the last five sites visited, shown by the
  Home button, new incognito tabs and when the last tab closes.
- **AetherNet branding** — name, icon, animated startup screen and wordmark.
- **Incognito** turns the whole app dark, web pages included.
- The home page follows the app theme as it changes, and setup no longer asks for appearance,
  layout or backup restore.

Everything else — the content blocker, website blocker, download manager, user scripts, bookmarks,
history and themes — comes from Clint Browser upstream.
